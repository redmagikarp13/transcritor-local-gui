# --- Bibliotecas NVIDIA (CUDA) -------------------------------------------------
# Se você já tem o CUDA Toolkit 12 instalado no sistema, NÃO precisa instalar nada!
# O programa detecta automaticamente as DLLs em:
#   - CUDA_PATH (variável de ambiente)
#   - C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\*
#   - PATH do sistema
#
# Se NÃO tem o CUDA instalado, você pode instalar via pip (apenas para desenvolvimento):
#   pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
#
# Para o executável compilado, o CUDA Toolkit deve estar instalado no sistema.
# Baixe em: https://developer.nvidia.com/cuda-downloads
