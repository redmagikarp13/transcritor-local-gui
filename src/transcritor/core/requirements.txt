faster-whisper

# GUI dependencies
toml
customtkinter

# CLI drop-in compativel com o Whisper original (atalho opcional de linha de comando):
whisper-ctranslate2

# --- Bibliotecas NVIDIA (CUDA) -------------------------------------------------
# O faster-whisper precisa de CUDA 12. Se você tem CUDA 13 (ou outro) instalado,
# instale as bibliotecas pip abaixo que contêm CUDA 12 e funcionam junto:
#
#   pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
#
# O programa detecta automaticamente e usa as bibliotecas pip em vez do CUDA do sistema.
# Não precisa fazer downgrade do CUDA instalado!
#
# Se você já tem CUDA 12 instalado no sistema, o programa também detecta automaticamente.
# Baixe o CUDA Toolkit em: https://developer.nvidia.com/cuda-downloads
#
