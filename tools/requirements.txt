# --- Bibliotecas NVIDIA (CUDA) -------------------------------------------------
# NAO sao instaladas aqui de proposito. Motivos:
#   1) So fazem sentido se voce for usar a GPU (device = "cuda"). Em CPU sao inuteis.
#   2) O faster-whisper NAO as puxa automaticamente: o requirements.txt dele lista
#      apenas ctranslate2, tokenizers, onnxruntime, av, tqdm, huggingface_hub --
#      nenhum pacote nvidia-*. Voce precisa instala-las a mao.
#
# Se for usar GPU, rode (ver setup/install.md, passo 3):
#   pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
#
# Atencao ao pin do cuDNN: o CTranslate2 atual (>=4.5, que vem com o faster-whisper
# recente) exige cuDNN *major version 9* para CUDA 12 -- NAO a serie 8.x.
# No Windows as DLLs nao entram no PATH sozinhas; veja o passo 3.3 do install.md.
